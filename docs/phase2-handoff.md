## 3. 功能说明

### 导出 / 导入

- **导出内容**：男戒收藏、女戒收藏、已保存组合、评论、当前 tab、当前筛选状态。
- **不导出的内容**：上传照片（保留在当前浏览器 IndexedDB 中）。
- **导入策略**：
  - 合并导入：与现有数据去重合并，不覆盖已有评论。
  - 覆盖导入：清空当前本地数据后写入文件内容。
- **导入校验**：检查 `version` 与数组字段格式，失败时弹窗提示。

### 清空本地数据

- **清空内容**：男戒收藏、女戒收藏、已保存组合、评论、IndexedDB 照片。
- **是否有确认**：是，弹窗二次确认。
- **是否可恢复**：否，清空后不可恢复。

### 收藏与匹配

- **展示字段**：
  - 男戒/女戒分别展示品牌、名称、材质、价格、官网链接。
  - 合计预算：两枚价格可计算时显示具体金额；否则提示“预算需人工确认”。
- **预算计算逻辑**：
  - 若两枚都有 `price.amount` 数值，计算合计。
  - 若任一为“需询价”或无明确金额，显示“预算需人工确认”。
- **超预算提示**：合计超过 ¥100,000 时，预算数字变为玫瑰色并显示“超过 ¥100,000 预算”。
- **推荐理由**：
  - 若 `data/pairs.js` 中存在对应组合，显示系统推荐理由和标签。
  - 若不存在，显示“这是自定义组合”，允许填写备注后保存。

### URL 状态

- **支持参数**：`tab`、`q`（搜索）、`budget`、`brand`、`material`、`style`、`gender`。
- **是否写入本地隐私数据**：否，收藏、评论、照片不会写入 URL。
- **实现方式**：切换 tab 或调整筛选时使用 `history.replaceState` 更新 URL，刷新后可恢复。
